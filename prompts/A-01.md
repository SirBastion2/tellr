## Steps (tests first)

1. `pyproject.toml` (Python 3.12: fastapi, uvicorn, pydantic v2, pyyaml, pytest, ruff, import-linter). `Makefile` targets `dev-api` (inside tmux, see WORKFLOW §2.4), `test`, `gate`. `.importlinter`: `engine` must not import `api`, `store`, or `recommenders`.
2. **Tests first, `tests/library/`:** the shipped library boots; an unresolved ID fails boot; a yes/no question without `asserts_on` fails boot; a signal without a rationale fails boot; the export served at `/library` validates against `contract/library.schema.json`.
3. Port the library from `reference_impl.py` into `library/*.yaml` (patterns, look-alikes, purposes, questions, signals with weights, context chips per §5.7), taking copy from `contract/library.json`. Start with the six questions; the bank grows toward ~40 in A-06. Mark the three patterns the architecture doesn't specify `review: compliance` (draft §7.3).
4. **Tests first, `tests/store/`:** the behaviors in §10.1: a live session with a scenario is rejected; an orphan event is rejected; `UPDATE` on events is rejected; deleting events of an open session is rejected; purge works events-first and fails session-first.
5. `store/sqlite.py`: the §10.1 SQL verbatim, a connection factory that sets `PRAGMA foreign_keys = ON` on every connection, and `purge(retention_days)` in one transaction, events first.
